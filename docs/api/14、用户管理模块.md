# 用户管理模块 API 文档

## 📋 概述

用户管理模块提供基于实体建模的动态用户管理功能。该模块的核心理念是：

1. **实体建模** → 定义角色实体（如医生、患者）及其属性，标记 `is_role: true`
2. **角色管理** → 自动识别角色实体，沿用实体定义，授予权限
3. **用户管理** → 基于角色创建用户，用户属性来自对应的角色实体定义

### 系统架构流程

```
实体建模层
├── 医生实体 (is_role: true)
│   ├── 姓名 (string, required)
│   ├── 工号 (string, required)
│   ├── 科室 (string)
│   └── 职称 (string)
├── 患者实体 (is_role: true)
│   ├── 姓名 (string, required)
│   ├── 身份证号 (string, required)
│   ├── 年龄 (number)
│   └── 联系电话 (string)
└── 设备实体 (is_role: false) // 不是角色，不会出现在用户管理中

角色管理层
├── 医生角色 (基于医生实体)
│   ├── 继承医生实体的所有属性
│   └── 授予诊疗相关权限
└── 患者角色 (基于患者实体)
    ├── 继承患者实体的所有属性
    └── 授予基础访问权限

用户管理层
├── 张医生 (医生角色)
│   ├── 姓名: "张三"
│   ├── 工号: "DOC001"
│   ├── 科室: "内科"
│   └── 职称: "主治医师"
└── 李患者 (患者角色)
    ├── 姓名: "李四"
    ├── 身份证号: "123456789012345678"
    ├── 年龄: 35
    └── 联系电话: "13800138000"
```

### 核心特性

- **动态表单生成**：根据角色实体的字段定义自动生成用户创建/编辑表单
- **类型安全**：用户属性严格遵循角色实体的字段类型和验证规则
- **权限继承**：用户自动继承所属角色的权限配置
- **灵活扩展**：新增角色实体即可支持新类型的用户管理

## API 详细文档

### 1. 获取用户列表

**GET** `/api/v1/users`

#### 描述
获取系统中所有用户的列表，支持分页、筛选和搜索功能。

#### 请求参数

**查询参数：**

| 参数 | 类型 | 必填 | 默认值 | 描述 |
|------|------|------|--------|------|
| page | integer | 否 | 1 | 页码 |
| limit | integer | 否 | 20 | 每页数量 |
| role_id | string | 否 | - | 按角色ID筛选 |
| status | string | 否 | - | 按状态筛选（active/inactive） |
| search | string | 否 | - | 搜索关键词（用户名、邮箱、真实姓名） |

#### 响应示例

**成功响应 (200):**
```json
{
  "code": 200,
  "message": "获取用户列表成功",
  "data": {
    "users": [
      {
        "id": 1,
        "username": "testuser",
        "email": "test@example.com",
        "real_name": "测试用户",
        "phone": "13800138000",
        "is_active": true,
        "role": {
          "id": "role_001",
          "name": "普通用户",
          "code": "user",
          "description": "系统普通用户"
        },
        "created_at": "2024-01-01T00:00:00Z",
        "last_login": "2024-01-02T10:30:00Z",

      "page": 1,

      "total": 50,
      "pages": 3

```

### 2. 创建用户（管理员）

**POST** `/api/v1/users`

#### 描述
管理员创建新用户账户，必须指定用户角色。

#### 请求参数

**Content-Type:** `application/json`

**请求体：**
```json
{
  "username": "string",
  "email": "string",
  "password": "string",
  "phone": "string",
  "real_name": "string",
  "role_id": "string",
  "is_active": true,
  "avatar_url": "string",
  "bio": "string"
}
```

| 参数 | 类型 | 必填 | 描述 |
|------|------|------|------|
| username | string | 是 | 用户名，3-20字符，只能包含字母、数字和下划线 |
| email | string | 是 | 邮箱地址，必须是有效的邮箱格式 |
| password | string | 是 | 密码，6-20字符 |
| phone | string | 否 | 手机号码，必须是有效的中国手机号 |
| real_name | string | 否 | 真实姓名 |
| role_id | string | 是 | 角色ID，必须是系统中存在的激活角色 |
| is_active | boolean | 否 | 用户状态，默认为true |
| avatar_url | string | 否 | 用户头像URL |
| bio | string | 否 | 个人简介 |

#### 响应示例

**成功响应 (201):**
```json
{
  "code": 201,
  "message": "用户创建成功",
  "data": {
    "user_id": 1,
    "username": "testuser",
    "email": "test@example.com",
    "real_name": "测试用户",
    "phone": "13800138000",
    "is_active": true,
    "role": {
      "id": "role_001",
      "name": "普通用户",
      "code": "user",
      "description": "系统普通用户"
    },
    "created_at": "2024-01-01T00:00:00Z",
    "created_by": "admin"
  }
}
```

**错误响应 (409):**
```json
{
  "code": 409,
  "message": "用户名或邮箱已存在",
  "data": null
}
```

### 8. 获取用户表单schema

#### 描述

1. 查找所有标记为角色的实体
2. 根据实体的字段定义生成表单字段
3. 应用字段的类型、验证规则和显示配置
4. 如果没有找到角色实体，返回默认的用户表单配置

#### 请求参数

| 参数 | 类型 | 必填 | 默认值 | 描述 |

| role_id | string | 否 | - | 指定角色ID，获取该角色对应实体的表单schema |

## 🧪 使用示例

### Python 示例

```python
import requests

# 创建用户
def create_user():
    url = "http://localhost:5000/api/v1/users"
    headers = {
        "Authorization": "Bearer YOUR_DEVELOPER_TOKEN",
        "Content-Type": "application/json"
    }
    data = {
        "username": "newuser",
        "email": "newuser@example.com",
        "password": "password123",
        "real_name": "新用户",
        "role_id": "role_001",
        "is_active": True
    }
    
    response = requests.post(url, json=data, headers=headers)
    return response.json()

# 获取用户列表
def get_users():
    url = "http://localhost:5000/api/v1/users"
    headers = {"Authorization": "Bearer YOUR_DEVELOPER_TOKEN"}
    params = {"page": 1, "limit": 10}
    
    response = requests.get(url, params=params, headers=headers)
    return response.json()
```

### JavaScript 示例

```javascript
// 创建用户
async function createUser() {
    const response = await fetch('/api/v1/users', {
        method: 'POST',
        headers: {
            'Authorization': 'Bearer YOUR_DEVELOPER_TOKEN',
            'Content-Type': 'application/json'
        },
        body: JSON.stringify({
            username: 'newuser',
            email: 'newuser@example.com',
            password: 'password123',
            real_name: '新用户',
            role_id: 'role_001',
            is_active: true
        })
    });
    
    return await response.json();
}

// 更新用户状态
async function toggleUserStatus(userId, isActive) {
    const response = await fetch(`/api/v1/users/${userId}/status?is_active=${isActive}`, {
        method: 'PUT',
        headers: {
            'Authorization': 'Bearer YOUR_DEVELOPER_TOKEN'
        }
    });
    
    return await response.json();
}
```

## 📋 实体建模前端功能说明

### 字段管理界面

实体建模前端现已支持完整的字段管理功能：

1. **字段列表显示**
   - 显示字段名称（显示名称 + 字段名）
   - 显示字段类型（带颜色标签）
   - 显示必填状态（必填/可选）
   - 显示唯一状态（唯一/普通）

2. **字段操作功能**
   - 添加字段：完整的字段创建表单
   - 编辑字段：修改字段属性
   - 删除字段：删除不需要的字段

3. **字段类型支持**
   - 文本（string）
   - 长文本（text）
   - 数字（number）
   - 布尔值（boolean）
   - 日期（date）
   - 日期时间（datetime）
   - 文件（file）
   - 图片（image）
   - JSON（json）

4. **字段验证规则**
   - 必填验证
   - 唯一性验证
   - 字段名称格式验证（字母开头，字母数字下划线）
   - 自定义验证规则

5. **用户体验优化**
   - 模态框界面，操作便捷
   - 实时表单验证
   - 操作成功提示
   - 数据自动刷新

### 角色实体标记

实体建模前端现已支持角色实体标记功能：

1. **角色实体列显示**
   - 在实体列表中显示"角色实体"列
   - 紫色标签显示"角色实体"
   - 灰色标签显示"普通实体"

2. **角色标记编辑**
   - 在实体创建/编辑表单中添加"角色实体"开关
   - 支持创建时设置角色标记
   - 支持编辑时修改角色标记

3. **自动角色同步**
   - 标记为角色的实体自动在角色管理中创建对应角色
   - 用户管理基于角色实体动态生成表单
