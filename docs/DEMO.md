# 三分钟体验 AILF

**在线体验：[mxyooR.github.io/AILF_open](https://mxyooR.github.io/AILF_open/)**。本地入口为 `http://localhost:3000/demo`。首页复用应用的 Siri 光球和流动极光背景，演示预置需求如何变成可操作的 AMIS 界面。业务数据和选择只保留在当前页面，无需登录或模型服务。

GitHub Pages 通过 CI 自动发布静态演示。在线版的「部署完整应用」指向部署文档；完整的开发者配置、用户认证和模型推理仍需自行运行后端。

## 启动

需要 Node.js 20+ 和 pnpm 10.13.1。已有环境可直接复用。

```bash
git clone https://github.com/mxyooR/AILF_open.git
cd AILF_open
pnpm install --frozen-lockfile
pnpm dev
```

也可以单独运行演示容器：

```bash
docker compose -f docker-compose.demo.yml up --build -d
```

## 演示顺序

1. 在 Siri 首页输入「帮我查一下北京到上海的高铁」并发送，或直接点击「查询高铁」。弹出的工作台可修改出发地、目的地和席别，再查询并选择车次。
2. 切换「Schema」，查看 AMIS JSON，包括字段、数据源和操作。切回业务界面时会重建表单并恢复默认条件。
3. 点击关闭按钮或按 Escape 返回 Siri 界面，再体验「查找耳机」和「预约门诊」。
4. 点击 Siri 光球可开始语音输入，识别后点击发送。浏览器不支持、麦克风被拒绝或识别服务不可用时，可继续使用文字和示例按钮。
5. 点击「示例工作台」或向下滚动，可在页面内同时查看条件、结果和流程步骤。铁路切换一等座、商品切换价格排序、门诊切换下午时段后，观察结果更新。
6. 通过下方的架构介绍了解完整系统如何加入候选召回、模型推理、工作流和权限检查。

语音输入仅在点击光球后启动，由浏览器识别服务处理，可能需要浏览器向其服务提供商发送音频；此页不下载 Whisper 模型。示例选择使用固定关键词与内置场景，无法处理的需求会提示支持范围，不会调用后台模型。

## 展示时应说明

此页的意图和数据是预置样例；真实使用时，模型在已配置的业务候选中选择并提取字段，后端组装 Schema。示例车次、商品、时段和价格没有实际业务含义，不进行真实交易。

前端单元测试覆盖条件更新、排序、场景隔离、有效条目选择和外部 URL 拒绝。完整推理、数据库写入和真实服务对接需要独立部署与验证，见[部署指南](DEPLOYMENT.md)。
