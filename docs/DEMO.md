# 三分钟体验 AILF

**在线体验：[mxyooR.github.io/AILF_open](https://mxyooR.github.io/AILF_open/)**。本地入口为 `http://localhost:3000/demo`。演示展示预置需求如何变成可操作的 AMIS 界面，所有数据和操作仅存在于当前浏览器页面，无需登录或模型服务。

GitHub Pages 通过 CI 自动发布静态演示。在线版的「部署完整应用」指向部署文档；完整的开发者配置、用户认证和模型推理仍需自行运行后端。

## 启动

需要 Node.js 20+ 和 pnpm 10.13.1。已有环境可直接复用。

```bash
git clone https://github.com/mxyooR/AILF_open.git
cd AILF_open
pnpm install --frozen-lockfile
pnpm dev
```

也可以单独运行演示容器：

```bash
docker compose -f docker-compose.demo.yml up --build -d
```

## 演示顺序

1. 选择「铁路出行」，点击「生成演示界面」。将出发地改为杭州、目的地改为南京、席别改为一等座，再查询，观察结果字段和示例价格更新。
2. 点击任一「选择车次」，查看本地完成提示。重置可以重新体验。
3. 切换「Schema」，展示界面对应的 AMIS JSON，包括字段、数据源和操作。切回业务界面时会重建表单并恢复默认条件。
4. 选择「商品检索」并生成，切换分类或价格排序后查询。
5. 选择「门诊预约」并生成，修改科室和时段后查询，完成一次本地选择。
6. 通过页面下方的架构介绍说明完整系统如何加入候选召回、模型推理、工作流和权限检查。

## 展示时应说明

此页的意图和数据是预置样例；真实使用时，模型在已配置的业务候选中选择并提取字段，后端组装 Schema。示例车次、商品、时段和价格没有实际业务含义，不进行真实交易。

前端单元测试覆盖条件更新、排序、场景隔离、有效条目选择和外部 URL 拒绝。完整推理、数据库写入和真实服务对接需要独立部署与验证，见[部署指南](DEPLOYMENT.md)。
