# 前端业务链路修复与验证

两个仓库共用的业务前端同步修复，关键判断和异步处理已加中文注释。开源演示页面与私有异步任务接口保留各自行为。

## 用户操作与结果

| 问题 | 修复后的行为 |
| --- | --- |
| AMIS 忽略外层状态，HTTP 200 的业务失败被当成成功 | fetcher 返回 AMIS 要求的 Axios 形状；保留原 code 等字段兼容模板 adaptor |
| 失败响应的 data 覆盖表单输入 | 失败数据不回填，错误消息和字段校验信息仍保留 |
| 登录后重复接续、录音按钮重置运行状态、旧响应重开界面 | 同步请求锁防重，支持取消；关闭、退出、切换账号和卸载时取消轮询，迟到响应不改页面 |
| 注册成功返回 201 却显示失败 | 注册接受 200 / 201；退出立即清除本地身份与业务界面 |
| 旧令牌刷新覆盖新登录，短有效期导致连续刷新 | 用户与开发者各自合并并发刷新，校验会话快照，短有效期采用延迟刷新 |
| 退出/卸载后迟到登录重新建立身份，旧开发者校验或登出清掉新登录 | 登录响应校验请求版本和会话快照；开发者先清本地身份，以退出前令牌登出；临时校验故障不清除有效身份 |
| 应用配置异常导致首页白屏或保存误报成功 | 校验 HTTP、业务状态和配置字段；失败时保留默认配置并报告错误 |
| 上传误报成功、下载 JSON 错误文件、批量文件测试误报成功 | 识别 HTTP 200 中的业务失败；下载前检查响应副本，保留原始文件流；图片测试同时检查内容类型 |
| 生产工作流详情依赖 window 调试客户端 | 使用正式开发者客户端，失败显示错误和重试，不回退到虚构示例 |
| 切换/新建工作流后沿用旧画布 | 先清理旧详情，只有当前选择的详情能进入画布；保存使用该工作流 ID |
| 保存草稿自动启用，页面模拟测试直接提示成功 | 保存保留原状态；通过明确的启用按钮调用后端校验；移除虚假的测试完成操作 |
| 日期转 UTC 导致前一天、清空字段无效、失败后丢输入 | date 提交 YYYY-MM-DD，datetime 提交无时区本地时间；null 明确提交；失败保留输入 |
| 编辑记录后新建仍带旧值，JSON 字段无法正确编辑 | 切换时重置表单；日期默认值转选择器对象；JSON 校验并解析 |
| 通知失败仍标已读，删除后留在空页，切账号混入旧列表 | 统一拒绝业务失败；序列化修改；成功后重读真实数量；最后一条删除回退分页 |
| 语音状态文字被当作指令，临时结果被提交 | 转写有独立忙碌状态；在线只提交最终结果；不把“正在识别”等提示放进 transcript |
| 页面关闭后麦克风、Blob URL 或媒体请求未释放 | 停止录音、关闭音频资源、取消媒体请求和释放对象 URL，忽略迟到数据 |
| 普通 API 导航被预加载并替换成下载地址 | 只对明确附件链接执行带身份的媒体预加载 |
| 首页菜单只能悬停，Escape 后焦点仍让它展开 | 使用按钮状态统一控制点击、触屏和键盘操作；Escape 可关闭；请求中可明确取消 |

自动附加的用户令牌只发送到本应用 API；接口消息按文本显示，诊断提示也不执行接口返回的 HTML。

## 验证

2026-11-08 至 2026-11-09 本地实际执行：

- 开源版：20 个前端测试文件、108 项通过；私有版：16 个测试文件、81 项通过。
- 两边全量 TypeScript 检查通过。复用已有依赖，没有安装新依赖。
- 回归覆盖 AMIS 传输、身份刷新、注册/退出与迟到登录、配置异常、文件业务失败、取消与防重、通知归属与分页、工作流详情与草稿保存、记录表单日期/清空/重试、语音最终结果与资源清理、媒体取消与释放。
- 最终源码的完整应用生产构建通过，保留既有 ESLint、Browserslist、Autoprefixer 等警告。
- Playwright 在生产构建中验证：普通表单业务失败保留输入；独立 POST 不误推进工作流；工作流失败可重试，完成页和语音正确；配置页能加载详情并切换不同工作流画布。
- 桌面菜单支持点击、Enter 和 Escape；390 × 844 手机视口验证取消后忽略迟到结果、再次提交及无横向溢出。配置接口返回 503 时，首页保留默认配置并继续使用。
- 两仓分别完成生产构建与首页业务浏览器验证；私有版本还验证了原有不带 `poll_token` 的异步接口兼容。

所有表单提交测试使用合成数据和模拟响应，未启动真实业务后端，也未修改真实配置或写入业务数据库。麦克风和模型推理通过替身验证，不代表真实设备或 GPU 识别效果已验收。取消前端轮询不会撤销已经派发的后端作业。
